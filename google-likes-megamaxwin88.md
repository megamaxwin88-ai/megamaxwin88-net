# Yang Disukai Google Search (Megamaxwin88)

Referensi diterapkan ke footer + meta-schema. Schema hanya untuk konten yang **terlihat**.

## Sudah dimasukkan ke paket

| Sinyal Google | Di mana |
|---------------|---------|
| Title unik + keyword brand | BO Title = `Megamaxwin88 Gacor: Depo Besar Untung Maxwin` |
| Meta description jelas | BO Meta Description |
| 1x H1 relevan | Footer `<h1>` |
| Hierarki H2 | Footer section |
| Konten helpful (bukan thin) | Footer penjelasan + langkah |
| Internal link deskriptif | Beranda / Daftar / Promo |
| FAQ terlihat + FAQPage schema | Footer FAQ + JSON-LD |
| HowTo terlihat + HowTo schema | 4 langkah + JSON-LD |
| Breadcrumb terlihat + BreadcrumbList | Nav + JSON-LD |
| Organization + WebSite + WebPage | JSON-LD |
| Canonical | Meta Script |
| robots index,follow + preview | Meta Script |
| Google site verification | Meta Script |
| Open Graph / Twitter | Meta Script |
| Bahasa jelas (id) | schema inLanguage id-ID |
| Trust / responsible | teks 18+ di footer |
| Crawl aids | robots.txt + sitemap.xml |

## Yang Google suka tapi butuh aksi di luar copy teks

| Sinyal | Status / tindakan |
|--------|-------------------|
| HTTPS | Sudah (megamaxwin88.net) |
| Mobile-friendly | Theme sudah mobile; jaga UI tidak overflow |
| Core Web Vitals (LCP/INP/CLS) | Ukur PageSpeed/CrUX; compress banner; kurangi JS berat |
| Sitemap di GSC | Upload sitemap + submit |
| Indexing bersih | Pastikan tidak noindex; pantau Coverage |
| E-E-A-T / helpful | Jaga konten akurat, update berkala, jangan spam keyword |
| OG image 1200x630 | Ganti dari logo ke banner brand khusus share |
| Backlink berkualitas | Jalur PBN/parasite terpisah; fokus brand anchor |
| Page experience | Hindari interstitial mengganggu, pastikan teks terbaca |

## Yang TIDAK boleh (Google benci / risky)

- Schema palsu (FAQ/review yang tidak ada di halaman)
- Keyword stuffing berlebihan
- Cloaking / konten beda untuk bot vs user
- Hidden text
- Doorway pages generik tanpa brand
- Duplicate meta description (BO + metaScript bersamaan)

## Urutan prioritas Google (ingat)

Crawlability -> Speed/CWV -> Mobile -> On-page -> Helpful content -> Links
